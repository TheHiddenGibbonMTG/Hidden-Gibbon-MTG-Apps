# Hidden Gibbon MTG — Official Software Downloads

Welcome to the official software distribution hub for **Hidden Gibbon MTG**!

We develop free companion applications for Magic: The Gathering players, collectors, and tournament organizers.

Our goal is to provide practical, accessible tools that make playing, collecting, and organizing Magic easier.

## Our Applications

###  Gibbon's Games With Friends
Track life totals, Commander damage, counters, timers, and game statistics.

**Platforms:** Windows | Android | iOS (planned)

###  Hidden Gibbon Collection Tracker
Manage your card collection, build decks, track prices, organize trades, and maintain wishlists.

**Platforms:** Windows | Android | iOS (planned)

###  Hidden Gibbon Rules Companion
A comprehensive reference for Magic: The Gathering rules, keywords, mechanics, formats, and advanced interactions.

**Platforms:** Windows | Android | iOS (planned)

###  Hidden Gibbon MTG Companion
Our three-in-one application combines Games With Friends, Collection Tracker, and Rules Companion into one unified experience.

**Platforms:** Windows | Android | iOS (planned)
